# JasonPlayground

This folder is the planning and study workspace for a VS Code-first GCP Data Engineering upskilling project.

Primary workbook:
- `gcp_medallion_learning_plan_jira_import.xlsx`

Recommended project-management tool:
- Jira Free, because it gives a solo learner a realistic agile workflow with backlog, board, timeline, reports, and CSV import practice while staying free for up to 10 users.

Scope:
- GitHub repository workflow
- VS Code terminal workflow on Windows
- Google Cloud first-time setup
- GCS bronze landing zone
- Dataproc and Spark development
- Silver cleansing and standardization
- Gold BigQuery marts
- Cloud Composer / Airflow orchestration
- Cost hygiene and cleanup

Excluded by design:
- Databricks
- dbt
